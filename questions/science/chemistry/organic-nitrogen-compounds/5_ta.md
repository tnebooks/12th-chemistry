**CH₃CH₂Br → KCN → A → H₂O⁺ → B → NH₃ → C → Br₂/NaOH → D. 'D' என்பது**

```markdown
CH₃CH₂Br + KCN → CH₃CH₂CN (A) (புரோப்பியோனிட்ரைல்)
CH₃CH₂CN + H₂O⁺ → CH₃CH₂COOH (B) (புரோப்பியோனிக் அமிலம்)
CH₃CH₂COOH + NH₃ → CH₃CH₂CONH₂ (C) (புரோப்பியோனமைடு)
CH₃CH₂CONH₂ + Br₂/NaOH → CH₃CH₂NH₂ (D) (புரோப்பிலமீன்)
ஆனால் விருப்பங்களில் மெத்திலமீன் உள்ளது. வினைத்தொடரில் இருந்து D என்பது புரோப்பிலமீன். சரியான விடை (இ) மெத்திலமீன்? இல்லை, D என்பது புரோப்பிலமீன் (CH₃CH₂CH₂NH₂) ஆகும். விருப்பங்களில் (இ) மெத்திலமீன் உள்ளது. D என்பது புரோப்பிலமீன்.
```
