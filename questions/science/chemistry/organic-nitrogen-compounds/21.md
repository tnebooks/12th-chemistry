**Identify X in the sequence given below:**
**NH$_2$ + CHCl$_3$ + KOH → (Y) → HCl (300K) → X + methanoic acid**

```markdown
Aniline (C₆H₅NH₂) reacts with CHCl₃ and KOH to give phenyl isocyanide (C₆H₅NC). Phenyl isocyanide on hydrolysis with HCl gives aniline (C₆H₅NH₂) and methanoic acid (HCOOH). Therefore, X is aniline (C₆H₅NH₂). The structure represented is H₂N-Cl which corresponds to aniline. Therefore, the correct answer is option (a).
```
