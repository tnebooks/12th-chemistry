**Which one of the following will not undergo Hofmann bromamide reaction?**

```markdown
Hofmann bromamide reaction requires a primary amide (-CONH₂). CH₃CONHCH₃ is a secondary amide (N-methylacetamide), so it will not undergo Hofmann bromamide degradation. CH₃CH₂CONH₂, CH₃CONH₂, and C₆H₅CONH₂ are all primary amides and will undergo the reaction. Therefore, the correct answer is CH₃CONHCH₃.
```
