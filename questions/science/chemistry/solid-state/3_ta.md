**கனசதுர நெருங்கிப் பொதிந்த அமைப்பில், நெருங்கிப் பொதிந்த அணுக்களுக்கும், நான்முகி துவாரங்களுக்கும் இடையேயான விகிதம்**

```markdown
கனசதுர நெருங்கிப் பொதிந்த (ccp) அமைப்பில், N அணுக்கள் இருந்தால் N நான்முகி துவாரங்கள் (tetrahedral voids) மற்றும் N/2 எண்முகி துவாரங்கள் (octahedral voids) உள்ளன. உண்மையில், ccp/fcc அமைப்பில் N அணுக்களுக்கு 2N நான்முகி துவாரங்கள் உள்ளன. எனவே நெருங்கிப் பொதிந்த அணுக்கள் : நான்முகி துவாரங்கள் = N : 2N = 1 : 2.
```
