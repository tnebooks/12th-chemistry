**ஒரு திண்மத்தில், M என்ற அணுக்கள் ccp அணிக்கோவைப் புள்ளிகளில் இடம்பெறுகின்றன. மேலும் 1/3 பங்கு நான்முகி வெற்றிடங்கள் N என்ற அணுவால் நிரப்பப்பட்டுள்ளது. M மற்றும் N ஆகிய அணுக்களால் உருவாகும் திண்மத்தின் வாய்ப்பாடு**

```markdown
ccp அமைப்பில் M அணுக்களின் எண்ணிக்கை = N (ஒரு அலகுக்கூறில் 4). நான்முகி வெற்றிடங்களின் எண்ணிக்கை = 2N. இதில் 1/3 பங்கு N அணுவால் நிரப்பப்பட்டுள்ளது. எனவே N அணுக்களின் எண்ணிக்கை = (1/3) × 2N = 2N/3. M : N = N : (2N/3) = 3 : 2. வாய்ப்பாடு M₃N₂. சரியான விடை (ஈ).
```
