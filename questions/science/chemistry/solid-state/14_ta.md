**எளிய கனச்சதுர (simple cubic) அமைப்பில் மொத்த கனஅளவில் அணுக்களால் அடைத்துக் கொள்ளப்படும் கனஅளவின் விகிதம்**

```markdown
எளிய கனச்சதுரத்தில், ஒரு அலகுக்கூறில் 1 அணு உள்ளது. a = 2r (விளிம்பு நீளம் = 2r). நிரப்பும் திறன் = (1 × (4/3)πr³) / a³ = (4/3)πr³ / (2r)³ = (4/3)πr³ / 8r³ = π/6. சரியான விடை (ஆ) π/6.
```
