**In calcium fluoride, having the fluorite structure the coordination number of Ca²⁺ ion and F⁻ ion are (NEET)**

```markdown
In CaF₂ (fluorite) structure, Ca²⁺ ions occupy fcc positions and F⁻ ions occupy all tetrahedral voids. Each Ca²⁺ ion is surrounded by 8 F⁻ ions, so coordination number of Ca²⁺ is 8. Each F⁻ ion is surrounded by 4 Ca²⁺ ions, so coordination number of F⁻ is 4. Correct answer is (c) 8 and 4.
```
