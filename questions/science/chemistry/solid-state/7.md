**The number of unit cells in 8 gm of an element X (atomic mass 40) which crystallizes in bcc pattern is (Nₐ is the Avogadro number)**

```markdown
Number of moles = 8/40 = 0.2 mol. Number of atoms in 0.2 mol = 0.2 × 6.023 × 10²³ = 1.2046 × 10²³ atoms. In bcc structure, each unit cell contains 2 atoms. Number of unit cells = (1.2046 × 10²³)/2 = 6.023 × 10²². Correct answer is (b) 6.023 × 10²².
```
