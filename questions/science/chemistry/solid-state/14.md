**The fraction of total volume occupied by the atoms in a simple cubic is**

```markdown
In simple cubic, one unit cell contains 1 atom. a = 2r (edge length = 2r). Packing efficiency = (1 × (4/3)πr³) / a³ = (4/3)πr³ / (2r)³ = (4/3)πr³ / 8r³ = π/6. Correct answer is (b) π/6.
```
