**sc, bcc மற்றும் fcc ஆகிய கன அமைப்புகளின் விளிம்பு நீளத்தினை 'a' எனக் குறிப்பிட்டால், அவ்வமைப்புகளில் காணப்படும் கோளங்களின் ஆரங்களின் விகிதங்கள் முறையே**

```markdown
எளிய கனச்சதுரம் (sc) - a = 2r → r = a/2 = 0.5a. bcc - a√3 = 4r → r = a√3/4. fcc - a√2 = 4r → r = a/(2√2). எனவே விகிதங்கள்: (a/2) : (a√3/4) : (a/(2√2)). சரியான விடை (ஆ) மற்றும் (இ) ஒரே மாதிரியானவை.
```
