**The radius of an atom is 300pm, if it crystallizes in a face centered cubic lattice, the length of the edge of the unit cell is**

```markdown
In fcc structure, face diagonal = 4r = a√2 (where r = atomic radius, a = edge length). a = 4r/√2 = 4 × 300 / 1.414 = 1200/1.414 = 848.5 pm. Correct answer is (b) 848.5 pm.
```
