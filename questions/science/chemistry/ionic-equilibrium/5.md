**Conjugate base for Bronsted acids H₂O and HF are**

```markdown
According to Bronsted-Lowry theory, a conjugate base is formed when an acid donates a proton (H⁺).
H₂O → H⁺ + OH⁻ (conjugate base is OH⁻)
HF → H⁺ + F⁻ (conjugate base is F⁻)
Correct answer is (c) OH⁻ and F⁻, respectively.
```
