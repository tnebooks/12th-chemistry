**Which of the following can act as Lowry-Bronsted acid as well as base?**

```markdown
A species that can both donate and accept a proton is amphiprotic.
HPO₄²⁻ can donate a proton: HPO₄²⁻ → H⁺ + PO₄³⁻ (acts as acid)
HPO₄²⁻ can accept a proton: HPO₄²⁻ + H⁺ → H₂PO₄⁻ (acts as base)
HCl - only acid, SO₄²⁻ - only base, Br⁻ - only base.
Correct answer is (c) HPO₄²⁻.
```
