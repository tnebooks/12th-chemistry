**The pH of an aqueous solution is Zero. The solution is**

```markdown
pH = -log[H⁺]
If pH = 0, then [H⁺] = 10⁰ = 1 M
The solution has [H⁺] = 1 M, which is strongly acidic.
Correct answer is (b) strongly acidic.
```
