**Which of these is not likely to act as Lewis base?**

```markdown
BF₃ - electron deficient (has empty p-orbital) → Lewis acid (not a base).
PF₃ - has lone pair on P → Lewis base.
CO - has lone pair on C → Lewis base.
F⁻ - has lone pairs → Lewis base.
Correct answer is (a) BF₃.
```
