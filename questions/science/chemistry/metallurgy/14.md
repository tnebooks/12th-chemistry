Zinc is obtained from ZnO by

```markdown
Zinc oxide (ZnO) is reduced to zinc metal by carbon reduction (smelting). ZnO + C → Zn + CO. This is done in a retort or blast furnace. ZnO cannot be reduced by electrochemical process (that's for Al). Silver is not used as a reducing agent. Acid leaching is used for ores like ZnS, not for ZnO directly.
```
