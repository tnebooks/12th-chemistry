**The button cell used in watches functions as follows: Zn(s) + Ag₂O(s) + H₂O(l) ⇌ 2Ag(s) + Zn²⁺(aq) + 2OH⁻(aq). The half cell potentials are: Ag₂O(s) + H₂O(l) + 2e⁻ → 2Ag(s) + 2OH⁻(aq) E° = 0.34 V; Zn(s) → Zn²⁺(aq) + 2e⁻ E° = 0.76 V. The cell potential will be**

```markdown
Anodic oxidation: Zn(s) → Zn²⁺(aq) + 2e⁻, E°ox = 0.76 V
Cathodic reduction: Ag₂O(s) + H₂O(l) + 2e⁻ → 2Ag(s) + 2OH⁻(aq), E°red = 0.34 V
E°cell = E°ox + E°red = 0.76 + 0.34 = 1.10 V
Correct answer is (c) 1.10V.
```
