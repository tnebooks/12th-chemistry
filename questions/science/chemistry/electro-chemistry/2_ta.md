**பின்வரும் அரைக்கல வினைகளை கருதுக: Mn²⁺ + 2e⁻ → Mn E° = -1.18 V; Mn²⁺ → Mn³⁺ + e⁻ E° = -1.51 V. 3Mn²⁺ → Mn + 2Mn³⁺ என்ற வினைக்கான E° மற்றும் முன்னோக்கிய வினையின் சாத்தியம் முறையே**

```markdown
வினைக்கு: 3Mn²⁺ → Mn + 2Mn³⁺
எதிர்மின்வாய் (ஒடுக்கம்): Mn²⁺ + 2e⁻ → Mn, E°red = -1.18 V
நேர்மின்வாய் (ஆக்சிஜனேற்றம்): 2[Mn²⁺ → Mn³⁺ + e⁻], E°ox = -1.51 V
E°cell = E°ox + E°red = -1.51 + (-1.18) = -2.69 V
E°cell எதிர்மறையாக இருப்பதால், ΔG° நேர்மறையாகும், எனவே முன்னோக்கிய வினை தன்னிச்சையற்றது.
சரியான விடை (ஆ) -2.69V மற்றும் தன்னிச்சையற்றது.
```
