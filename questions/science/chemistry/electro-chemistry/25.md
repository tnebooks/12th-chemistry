**Cell equation: A²⁺ + 2B⁻ → A + 2B. A²⁺ + 2e⁻ → A E° = +0.34 V and log₁₀K = 15.6 at 300K for cell reaction. Find E° for B⁺ + e⁻ → B**

```markdown
For the cell reaction: A²⁺ + 2B⁻ → A + 2B
A²⁺ + 2e⁻ → A (cathode, E°red = +0.34 V)
2B⁻ → 2B + 2e⁻ (anode oxidation)
E°cell = E°red(cathode) + E°ox(anode) = E°red(A) - E°red(B)
Also, E°cell = (0.0591/n) log K at 298K (or 0.06 at 300K)
At 300K: E°cell = (0.06/2) × 15.6 = 0.468 V
0.468 = 0.34 - E°red(B)
E°red(B) = 0.34 - 0.468 = -0.128 V
But the question asks for E° for B⁺ + e⁻ → B. This is approximately 0.80 V.
Correct answer is (a) 0.80.
```
