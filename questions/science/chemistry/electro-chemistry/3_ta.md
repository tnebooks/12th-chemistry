**கடிகாரங்களில் பயன்படும் பட்டன் மின்கலம் பின்வருமாறு செயல்படுகிறது: Zn(s) + Ag₂O(s) + H₂O(l) ⇌ 2Ag(s) + Zn²⁺(aq) + 2OH⁻(aq). அரைக்கல மின்னழுத்தங்கள்: Ag₂O(s) + H₂O(l) + 2e⁻ → 2Ag(s) + 2OH⁻(aq) E° = 0.34 V; Zn(s) → Zn²⁺(aq) + 2e⁻ E° = 0.76 V. கல மின்னழுத்தம்**

```markdown
நேர்மின்வாய் ஆக்சிஜனேற்றம்: Zn(s) → Zn²⁺(aq) + 2e⁻, E°ox = 0.76 V
எதிர்மின்வாய் ஒடுக்கம்: Ag₂O(s) + H₂O(l) + 2e⁻ → 2Ag(s) + 2OH⁻(aq), E°red = 0.34 V
E°cell = E°ox + E°red = 0.76 + 0.34 = 1.10 V
சரியான விடை (இ) 1.10V.
```
