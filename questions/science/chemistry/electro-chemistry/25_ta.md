**கல வினை: A²⁺ + 2B⁻ → A + 2B. A²⁺ + 2e⁻ → A E° = +0.34 V மற்றும் 300K வெப்பநிலையில் log₁₀K = 15.6 எனில், B⁺ + e⁻ → B என்ற கல வினைக்கான E° மதிப்பைக் காண்க (AIIMS - 2018)**

```markdown
கல வினைக்கு: A²⁺ + 2B⁻ → A + 2B
A²⁺ + 2e⁻ → A (எதிர்மின்வாய், E°red = +0.34 V)
2B⁻ → 2B + 2e⁻ (நேர்மின்வாய் ஆக்சிஜனேற்றம்)
E°cell = E°red(எதிர்மின்வாய்) + E°ox(நேர்மின்வாய்) = E°red(A) - E°red(B)
மேலும், E°cell = (0.0591/n) log K at 298K (அல்லது 300K-ல் 0.06)
300K-ல்: E°cell = (0.06/2) × 15.6 = 0.468 V
0.468 = 0.34 - E°red(B)
E°red(B) = 0.34 - 0.468 = -0.128 V
ஆனால் கேள்வி B⁺ + e⁻ → B-க்கான E° கேட்கிறது. இது தோராயமாக 0.80 V ஆகும்.
சரியான விடை (அ) 0.80.
```
