**Calculate Λ°HOAC using appropriate molar conductances of the electrolytes listed: KCl = 149.9, KNO₃ = 145.0, HCl = 426.2, NaOAC = 91.0, NaCl = 126.5 S cm² mol⁻¹**

```markdown
Using Kohlrausch's law of independent migration of ions:
Λ°HOAC = Λ°HCl + Λ°NaOAC - Λ°NaCl
= 426.2 + 91.0 - 126.5 = 390.7 S cm² mol⁻¹
Correct answer is (c) 390.7.
```
