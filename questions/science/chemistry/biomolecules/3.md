**Which one given below is a non-reducing sugar? (NEET Phase – I)**

```markdown
Sucrose is a non-reducing sugar because the glycosidic linkage is between the anomeric carbons of both glucose and fructose, so no free anomeric -OH group is available for reduction. Glucose, maltose, and lactose are reducing sugars. Therefore, the correct answer is Sucrose.
```
