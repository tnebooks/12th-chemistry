**Glucose is an aldose. Which one of the following reactions is not expected with glucose?**

```markdown
Glucose does not react with Grignard reagents because the -OH groups present in glucose react with Grignard reagent first, and the open-chain form exists in very small concentration. Glucose forms oxime, osazones, and reduces Tollens reagent (being an aldose). Therefore, the correct answer is that it does not react with Grignard reagent.
```
