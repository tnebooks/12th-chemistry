**உலோக அயனியின் ஆக்சிஜனேற்ற எண் பூஜ்ஜிய மதிப்பினைப் பெற்றிருக்கும் அணைவு சேர்மம்**

```markdown
Fe(CO)₅ - இதில் CO ஒரு நடுநிலை ஈனி. Fe-ன் ஆக்சிஜனேற்ற நிலை 0 ஆகும். K₄[Fe(CN)₆]-ல் Fe = +2 (4K⁺ = +4, 6CN⁻ = -6, Fe = +2). Fe(CN)₃(NH₃)₂-ல் Fe = +3 (3CN⁻ = -3, 2NH₃ = 0, Fe = +3). எனவே Fe(CO)₅ மட்டுமே Fe-ன் ஆக்சிஜனேற்ற நிலை 0 ஆகும்.
```
