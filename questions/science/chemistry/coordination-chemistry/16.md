  - "[Fe(CO)₅]"

**A complex in which the oxidation number of the metal is zero is**

```markdown
In [Fe(CO)₅], CO is a neutral ligand. Fe has oxidation state 0. In K₄[Fe(CN)₆], Fe is +2 (4K⁺=+4, 6CN⁻=-6, so Fe=+2). In [Fe(CN)₃(NH₃)₃], Fe is +3 (3CN⁻=-3, 3NH₃=0, so Fe=+3). Therefore only [Fe(CO)₅] has Fe in zero oxidation state.
```
