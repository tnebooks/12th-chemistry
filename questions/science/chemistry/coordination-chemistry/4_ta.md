**[Fe(H₂O)₅NO]SO₄ என்ற அணைவுச் சேர்மத்தில் உள்ள உலோகம் மற்றும் NO-ன் ஆக்சிஜனேற்ற நிலைகள் முறையே**

```markdown
SO₄²⁻ ஒரு ஈரிணைதிறன் எதிர்மின் அயனி. மூலக்கூறு நடுநிலையானது. NO ஒரு நடுநிலை ஈனி (NO⁺ அல்ல). Fe-ன் ஆக்சிஜனேற்ற நிலை x எனில்: x + 0 (NO) + 5(0) (H₂O) - 2 (SO₄²⁻) = 0 → x = +2. ஆனால், [Fe(H₂O)₅NO]SO₄-ல் NO-வை NO⁺ எனக் கருதினால் Fe +1 ஆகவும், NO +1 ஆகவும் இருக்கும். எனவே Fe = +1, NO = +1.
```
