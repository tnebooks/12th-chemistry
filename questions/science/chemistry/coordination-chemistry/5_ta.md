**ஒரு d⁴ அமைப்பு உள்ள தாழ் சுற்றுச்சி (low spin) அணைவின் படிகப் புல நிலைப்படுத்தும் ஆற்றல் (CFSE) மதிப்பு**

```markdown
d⁴ தாழ் சுற்றுச்சி அமைப்பில், எலக்ட்ரான்கள் t₂g ஆர்பிட்டால்களில் முதலில் நிரம்பும். அமைப்பு: t₂g⁴ e_g⁰. CFSE = [4 × (-0.4) + 0 × (0.6)]Δ₀ = -1.6Δ₀. ஆனால், d⁴ தாழ் சுற்றுச்சியில் பிணைப்பு இணைதல் (pairing) ஆற்றல் P கருத்தில் கொள்ளப்பட வேண்டும். CFSE = -1.6Δ₀ + P. கேள்வியில் விருப்பங்களில் 0.6, 0.4, 1.2, 2.4 உள்ளன. d⁴ தாழ் சுற்றுச்சிக்கு CFSE = -1.6Δ₀ (விருப்பங்களில் 1.6 இல்லை). d⁵ தாழ் சுற்றுச்சிக்கு CFSE = 0 (t₂g⁵ e_g⁰ → 5 × (-0.4) = -2.0 + 2P). சரியான விடை 0 (d⁵-க்கு).
```
