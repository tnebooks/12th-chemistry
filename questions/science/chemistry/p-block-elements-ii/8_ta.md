**ஒரு ஆர்த்தோ பாஸ்போரிக் அமிலக் கரைசலின் மொலாரிட்டி 2M. அக்கரைசலின் நார்மாலிட்டி**

```markdown
ஆர்த்தோ பாஸ்போரிக் அமிலம் (H₃PO₄) ஒரு மூவகைய (tribasic) அமிலம். இதில் 3 பிரிக்கத்தக்க H⁺ அயனிகள் உள்ளன. நார்மாலிட்டி = மொலாரிட்டி × காரத்துவம். ∴ N = 2M × 3 = 6N. எனவே சரியான விடை 6N.
```
