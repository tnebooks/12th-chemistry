**The molarity of given orthophosphoric acid solution is 2M. Its normality is**

```markdown
Orthophosphoric acid (H₃PO₄) is a tribasic acid with 3 ionizable H⁺ ions (basicity = 3). Normality = Molarity × Basicity. Therefore, N = 2M × 3 = 6N. So the normality is 6N.
```
