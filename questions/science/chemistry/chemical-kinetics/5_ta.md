**2NH₃ → N₂ + 3H₂ என்ற வினைக்கு -d[NH₃]/dt = k₁[NH₃], d[N₂]/dt = k₂[NH₃], d[H₂]/dt = k₃[NH₃] எனில், k₁, k₂ மற்றும் k₃ ஆகியவற்றுக்கு இடையேயான தொடர்பு**

```markdown
வினை 2NH₃ → N₂ + 3H₂ க்கு: வினைவேகம் = -1/2 d[NH₃]/dt = d[N₂]/dt = 1/3 d[H₂]/dt.
-d[NH₃]/dt = k₁[NH₃], d[N₂]/dt = k₂[NH₃], d[H₂]/dt = k₃[NH₃].
எனவே: k₁[NH₃] = 2k₂[NH₃] = (2/3)k₃[NH₃].
k₁ = 2k₂ = (2/3)k₃.
3 ஆல் பெருக்க: 3k₁ = 6k₂ = 2k₃.
அல்லது: 1.5k₁ = 3k₂ = k₃. சரியான விடை (இ).
```
