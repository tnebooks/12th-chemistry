**In a reversible reaction, the enthalpy change and the activation energy in the forward direction are respectively -x kJ mol⁻¹ and y kJ mol⁻¹. Therefore, the energy of activation in the backward direction is**

```markdown
For a reversible reaction: ΔH = Ea(forward) - Ea(backward).
Given: ΔH = -x kJ/mol, Ea(forward) = y kJ/mol.
Therefore: -x = y - Ea(backward) → Ea(backward) = y + x = (x + y) kJ mol⁻¹.
Correct answer is (a) (y - x) kJ mol⁻¹? Wait: Ea(backward) = Ea(forward) - ΔH = y - (-x) = y + x. So Ea(backward) = (x + y) kJ mol⁻¹. Correct answer is (a) (y - x) kJ mol⁻¹ is wrong; it should be (x + y). But option (a) says (y - x) which is incorrect. The correct answer is (x + y) kJ mol⁻¹. None of the options match exactly. However, option (d) is (x + y) × 10³ J mol⁻¹ which is the same as (x + y) kJ mol⁻¹. So answer is (d).
```
