**A → B + C + D என்ற ஒரு முதல் வகை வினையில், துவக்க அழுத்தம் P₀, 't' நேரத்திற்குப் பின் P எனில், P₀, P மற்றும் t ஆகியவற்றைப் பொறுத்து வினைவேக மாறிலி**

```markdown
வினை A → B + C + D க்கு, துவக்க அழுத்தம் P₀ என்க. t நேரத்தில் x அழுத்தம் வினைப்பட்டது என்க.
t நேரத்தில் மொத்த அழுத்தம்: P = (P₀ - x) + x + x + x = P₀ + 2x.
எனவே x = (P - P₀)/2.
t நேரத்தில் A-ன் பகுதி அழுத்தம் = P₀ - x = P₀ - (P - P₀)/2 = (3P₀ - P)/2.
முதல் வகைக்கு: k = (2.303/t) log(P₀/(P₀ - x)) = (2.303/t) log(P₀ / ((3P₀ - P)/2)).
k = (2.303/t) log(2P₀/(3P₀ - P)).
சரியான விடை (அ).
```
