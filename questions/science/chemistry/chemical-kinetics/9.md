**Consider the following statements: (i) increase in concentration of the reactant increases the rate of a zero order reaction. (ii) rate constant k is equal to collision frequency A if Ea = 0 (iii) rate constant k is equal to collision frequency A if Ea = ∞ (iv) a plot of ln(k) vs T is a straight line. (v) a plot of ln(k) vs (1/T) is a straight line with a positive slope. Correct statements are**

```markdown
(i) False - For zero order, rate is independent of concentration.
(ii) True - If Ea = 0, k = A (from Arrhenius equation).
(iii) False - If Ea = ∞, k = 0, not A.
(iv) False - ln k vs T is not a straight line; ln k vs 1/T is a straight line.
(v) False - ln k vs 1/T gives a straight line with negative slope (-Ea/R), not positive.
Therefore only (ii) is correct. Answer is (a) (ii) only.
```
