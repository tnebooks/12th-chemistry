**Sc (Z=21) is a transition element but Zinc (Z=30) is not because**

```markdown
Transition elements are defined as elements with partially filled d-orbitals. Sc has electronic configuration [Ar]3d¹4s² - d-orbital is partially filled. Zn has electronic configuration [Ar]3d¹⁰4s² - d-orbital is completely filled (3d¹⁰). Therefore Zn is not a transition element. Sc³⁺ and Zn²⁺ being colourless is not the reason for this classification.
```
