**1 மோல் பொட்டாசியம் டைகுரோமேட் ஆனது பொட்டாசியம் அயோடைடுடன் வினைப்படும் போது வெளியிடும் அயோடினின் மோல்களின் எண்ணிக்கை?**

```markdown
K₂Cr₂O₇ + 6KI + 7H₂SO₄ → 4K₂SO₄ + Cr₂(SO₄)₃ + 7H₂O + 3I₂. சமன்பாட்டின் படி, 1 மோல் K₂Cr₂O₇ ஆனது 3 மோல் I₂-ஐ வெளியிடுகிறது. Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O மற்றும் 6I⁻ → 3I₂ + 6e⁻. எனவே 3 மோல் அயோடின் உருவாகிறது.
```
