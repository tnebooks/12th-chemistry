**Which one of the following characteristics are associated with adsorption? (NEET)**

```markdown
Adsorption is a spontaneous process, so ΔG is negative. It is exothermic, so ΔH is negative. When gas molecules adsorb on a solid surface, they become more ordered (less random), so entropy decreases; hence ΔS is negative. Therefore, ΔG, ΔH, and ΔS all are negative.
Correct answer is (d).
```
